# Task Tracker

The growing project of the series. It starts as ten lines in Module 01, and each module adds one step.

| Step | Built in |
|---|---|
| v1_basics | Module 01 |
| v2_operators | Module 02 |
| v3_strings | Module 03 |
| v4_data_structures | Module 04 |

Run any step from the repository root:

```bash
python task_tracker/v1_basics/task_tracker_v1.py
```
