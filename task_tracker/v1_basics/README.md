# Mini Project — Task Tracker v1

The first step of a project that grows through the whole series. In Module 01 it is just ten lines. By Module 16 it becomes a tested, packaged app.

## What it uses

| Idea | Lesson |
|---|---|
| Comments and `print()` | Lesson 01 |
| Variables and a constant (`APP_NAME`) | Lesson 02 |
| `input()`, `int()`, indentation, truthy and falsy | Lesson 03 |

## Run it

```bash
python task_tracker/v1_basics/task_tracker_v1.py
```

Example session:

```text
Welcome to Task Tracker
Task title: Record Lesson 04
Priority (1 = high, 3 = low): 1
Saved task: Record Lesson 04 | priority: 1
```

## Your turn

1. Add a second `input()` that asks for a due date, and print it too.
2. Change the program so it prints `High`, `Medium` or `Low` for priority 1, 2 or 3. (You will learn `if / elif` in Module 05.)
3. Add a comment above every line that explains why it is there.
